# RapeRiskClassifier-ML
An In-Depth Analysis of Rape Cases in India Using Machine Learning  

This project utilizes machine learning to analyze and predict trends in rape cases across India. The primary goal is to identify high-risk regions, understand crime patterns, and provide actionable insights using data visualization and geospatial mapping techniques.  

## 🌟 Key Features  

1. **Objective**:  
   - Predict high-risk regions for rape cases in India.  
   - Compare crime rates across states and districts.  
   - Visualize data trends and patterns using advanced geospatial mapping techniques.  

2. **Dataset**:  
   - Comprehensive dataset containing features such as:  
     - **Demographics**: Population, literacy rate, and estimated unemployment rate.  
     - **Crime Data**: Statistics on crimes such as rape, kidnapping, and other related offenses by region and year.  

3. **Machine Learning Techniques**:  
   - Algorithms Used:  
     - **Linear Regression**: Analyze trends over time.  
     - **Logistic Regression**: Classification of regions into high-risk and low-risk areas.  
     - **K-Nearest Neighbors (KNN)**: For clustering and crime rate predictions.  
   - Risk classification of regions based on average crime rates.  

4. **Data Visualization**:  
   - Comparison of crime rates across states and districts using:  
     - Box plots  
     - Bar charts  
   - Geospatial mapping for an intuitive view of high-risk areas.  

5. **Development Tools**:  
   - **Programming Language**: Python  
   - **Frameworks**: TensorFlow, scikit-learn  
   - **Visualization Libraries**: Matplotlib, Seaborn, Plotly  
   - **Geospatial Tools**: Geopandas, Folium  

6. **Key Metrics**:  
   - **Prediction Accuracy**: Evaluate the reliability of risk classification.  
   - **Region-Wise Insights**: Highlight regions requiring immediate attention.  

## 🚀 How It Works  

1. **Data Preprocessing**:  
   - Cleaned and prepared the dataset for analysis.  
   - Performed feature scaling and normalization.  

2. **Model Training**:  
   - Trained machine learning models on historical data to predict future trends.  

3. **Visualization**:  
   - Generated detailed graphs and interactive maps for easy interpretation.  

## 🌐 Applications  

- Policy-making: Helps authorities prioritize regions requiring additional resources.  
- Public Awareness: Educates citizens about high-risk areas.  
- Research: Provides a foundation for further studies on crime prevention.
